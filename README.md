## Getting started

### Prerequisites

- Python 3.10 or newer
- Git

### Clone the repository

```bash
git clone https://github.com/pranav100000/probot-test.git
cd probot-test
```

### Run the project

`main.py` is currently a placeholder. When application code is added, run it with:

```bash
python main.py
```

## Development

Create a virtual environment before adding dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
```

If dependencies are added later, document them here and include the appropriate requirements or project metadata file.
