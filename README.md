## Getting started

### Prerequisites

- Python 3.10 or newer
- Git

### Clone the repository

```bash
git clone https://github.com/pranav100000/probot-test.git
cd probot-test
```

### Run the project

Add your application code to `main.py`, then run:

```bash
python main.py
```
